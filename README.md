# My Gym Coach (web app installabile)

App locale e gratuita: questionario, schede, diario, foto di progresso, backup. Nessun account, nessun server: i dati restano nel dispositivo.

## Pubblicazione su GitHub Pages
1. Crea un account su github.com e un nuovo repository **pubblico** (es. `mygymcoach`).
2. Carica **tutti** i file di questa cartella nella radice del repository (Add file > Upload files).
3. Settings > Pages > Source: *Deploy from a branch* > Branch: `main`, cartella `/ (root)` > Save.
4. Dopo 1-2 minuti l'app è su `https://TUO-UTENTE.github.io/mygymcoach/`.

## Installazione su smartphone
- **iPhone (Safari):** apri il link > Condividi > *Aggiungi alla schermata Home*.
- **Android (Chrome):** apri il link > menu ⋮ > *Installa app*.

Dopo il primo avvio funziona anche offline. Per forzare un aggiornamento cambia `mgc-v1` in `sw.js`.

## Note
- Esporta il backup dalla Home ogni tanto: cancellare l'app o i dati del sito cancella anche i tuoi dati.
